# POSHAN SAATHI NXT v2.0

Intelligent Nutrition Companion, An AI powered personal Nutrition Counselor for Nepal.

## About The App

Poshan Saathi (Nutrition Friend) is a comprehensive, AI-driven nutrition application designed specifically for the Nepalese context. It provides personalized dietary advice, meal planning, and nutritional insights based on local ingredients, cultural practices, and individual health profiles.

### Key Features

* **Bilingual Support:** Fully accessible in both English and Nepali (नेपाली), ensuring nutrition advice is available to a wider audience.
* **Personalized Profiling:** Tailors recommendations based on your age, weight, health conditions, budget, and dietary preferences.
* **AI Chat Companion:** A conversational assistant ready to answer your nutrition queries in real-time.
* **Smart Nutrition Modules:**
  * 📸 **Plate Recognition:** Analyze your meals directly from photos.
  * 🔍 **Local Food Lookup:** Get detailed nutritional information for traditional Nepalese foods.
  * 💰 **Budget Meals:** Plan nutritious meals that fit your financial constraints.
  * 🩺 **Deficiency Checker:** Identify potential nutrient gaps based on your symptoms and diet.
  * 🌦️ **Seasonal Foods:** Discover the best local foods to eat depending on the season.
  * 🍲 **Recipe Generator:** Create healthy, culturally relevant recipes using ingredients you have.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `NEXT_PUBLIC_GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Run the app:
   `npm run dev`
